Automation Framework

Java automation testing framework for UI and API testing.

Technologies:
- Java 17
- Maven
- Selenium WebDriver
- TestNG
- REST Assured

Project structure:
src/test/java
- base    – base test setup
- pages   – Page Object Model classes
- tests   – UI and API tests

src/test/resources
- testng.xml – TestNG suite configuration

Run tests:
mvn clean test
